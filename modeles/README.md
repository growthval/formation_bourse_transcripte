# Modèles de documents

Gabarits copiés par les commandes Claude Code. Les champs `{{...}}` sont remplis à la création ; aucun ne
doit subsister dans une note finie.

| Modèle | Produit | Commande |
|---|---|---|
| `brief.md` | `veille/journal/AAAA-MM-JJ.md` | `/veille` |
| `fiche-video.md` | `veille/videos/<dossier>/fiche.md` (pré-remplie par `vigie video`) | `/analyse-video` |
| `verification.md` | `veille/verifications/AAAA-MM-JJ-<sujet>.md` | `/croiser` |
| `dossier.md` | `veille/dossiers/<theme>.md` ou `veille/dossiers/pays/<pays>.md` | `/dossier` |
| `scenario.md` | une section de `plan/scenarios.md` | `/anticiper scénario` |
| `these.md` | `plan/theses/<sujet>.md` | `/anticiper thèse` |
