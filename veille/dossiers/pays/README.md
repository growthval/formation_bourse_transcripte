# Dossiers par pays

Un fichier par pays ou région, même gabarit. Chaque pays « important » pour le plan a le sien ; en ajouter
un se fait avec `/dossier <pays>` (fichier en kebab-case, sans accent).

| Fichier | Pourquoi il compte |
|---|---|
| `etats-unis.md` | Première économie, dollar, marchés, IA, politique commerciale |
| `chine.md` | Deuxième économie, industrie, Taïwan, technologie |
| `union-europeenne.md` | Notre cadre : euro, régulation (AI Act, DMA), défense |
| `france.md` | Notre pays : fiscalité de l'épargne, politique, dette, élections |
| `allemagne.md` | Industrie européenne, énergie, budget |
| `royaume-uni.md` | Place financière, après-Brexit |
| `japon.md` | Dette, politique monétaire atypique, yen, Indo-Pacifique |
| `inde.md` | Croissance, démographie, place dans la rivalité États-Unis/Chine |
| `russie.md` | Guerre, énergie, sanctions |
| `taiwan.md` | Semi-conducteurs, risque militaire majeur |
| `moyen-orient.md` | Pétrole, détroits, Israël, Iran, Golfe |

## Gabarit d'un dossier pays
1. **Pourquoi ce pays compte pour le plan**
2. **Ce qu'on suit** : politique intérieure et calendrier électoral ; économie (croissance, inflation,
   dette, banque centrale) ; politique extérieure et alliances ; droit et régulation ; risques (sociaux,
   militaires, climatiques).
3. **Dates à venir** (vérifiées, avec source)
4. **État des lieux** (faits datés, sources A/B) — rempli par `/dossier`
5. **Lectures divergentes** : presse du pays, presse d'un rival ou voisin, source internationale
6. **Ce que ça change pour nous**
7. **Journal des mises à jour** et **Sources**
